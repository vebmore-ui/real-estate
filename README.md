# Shree Architects — Places for Living

A high-end architectural portfolio landing page built with Vite, Three.js (WebGL perspective corridor), GSAP + ScrollTrigger, and Lenis smooth scrolling.

## Features

- **Three.js WebGL Perspective Corridor**: Butter-smooth 60fps GPU-accelerated corridor with bilateral symmetry, 0% vibration, and bilinear mipmapped textures.
- **Editorial Typography**: Refined Cormorant Garamond serif with sage italic emphasis paired with clean Cinzel and DM Sans.
- **Hero Fade-Away Transition**: Soft scroll-scrubbed fade away into the editorial content.
- **Fixed Bottom Navigation**: Persistent bottom bar with frosted glass effect (`backdrop-filter`) and dividing line, smooth scroll navigation on click, and automatic hide on the closing contact section.
- **Horizontal Gallery Scrub**: Parallax gallery track scrubbed smoothly to page scroll.
- **Responsive & Accessible**: Adapts seamlessly from mobile to wide screens with reduced-motion support.

## Run Locally

```sh
npm install
npm run dev
```

For production build:

```sh
npm run build
npm run preview
```
